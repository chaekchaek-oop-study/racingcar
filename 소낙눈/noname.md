tdd

### 입력
자동차 이름 입력
- 쉼표로 구분
- 5자 이하

시도할 횟수 입력
- 양수라고 가정

### 출력
차수별 실행 결과 출력
- {이름} : {-}

우승자 출력
- 단독 우승자
  - 최종 우승자 : {이름}
- 공동 우승자
  - 최종 우승자 : {이름}, {이름}

### 전진 조건
- 0~9 난수를 구한 후 4 이상이면 전진

### 차
- 이름
- 현재 전진 횟수

### 에러
입력 에러
- 차 이름 5자 초과 / 1자 미만
- 차 이름 null / blank
- 시도 횟수 null / blank
- 시도 횟수 숫자 아님
- 시도 횟수 양수 아님
