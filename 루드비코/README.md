# java-racingcar-precourse

## 구현할 기능 목록

- 자동차는
  - [x] 이름을 가진다.
  - 위치를 가진다.
    - [x] 시작 위치는 `0`이다.
  - 이동할 수 있다.
    - [x] 전진의 단위는 1이다.
    - [x] 후진은 불가하다. 즉, 라운드 진행 후 위치가 이전 위치보다 작아질 수 없다.

- 자동차 위치는
  - [x] 0 이상의 정수이다.

- 자동차 이름은
  - [x] 1자 이상, 5자 이하만 가능하다.
  - [x] 영문만 가능하다.

- 자동차 이동 여부는
  - [x] 0부터 9 사이 숫자를 기준으로 결정한다.
    - [x] 숫자가 4 이상이면 전진
    - [x] 숫자가 4 미만이면 전진하지 않는다(정지).

- 레이싱 게임은
  - [x] 참가자가 최소 `2`명이다.
  - [x] 정해진 라운드 수만큼 진행된다.
    - [ ] 라운드 수는 `1`이상의 정수이다. 
  - [x] 우승자를 계산한다.

## 용어사전

| 한글      | 영문     |설명|
|---------|--------|---|
| 주어진 횟수  | rounds |주어진 횟수 동안 n대의 자동차는 전진 또는 멈춘다. 사용자가 입력한다.|
