# java-racingcar-precourse

## 구현할 기능 목록

- 자동차는
  - 위치를 가진다.
    - [ ] 위치는 정수이다.
    - [ ] 시작 위치는 `0`이다.
    - [ ] 위치는 음수일 수 없다.
  - 전진하거나 멈출 수 있다.
    - [ ] 전진할 수 있다. 전진의 단위는 1이다.
    - [ ] 멈출 수 있다.
    - [ ] 후진은 불가하다. 즉, 라운드 진행 후 위치가 이전 위치보다 작아질 수 없다.
    - 이름을 가질 수 있다.
      - [x] 1자 이상, 5자 이하만 가능하다.
      - [x] 영문만 가능하다.


## 용어사전

| 한글      | 영문     |설명|
|---------|--------|---|
| 주어진 횟수  | rounds |주어진 횟수 동안 n대의 자동차는 전진 또는 멈춘다. 사용자가 입력한다.|
