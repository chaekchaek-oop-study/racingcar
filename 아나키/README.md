# java-racingcar-precourse
**입력**

- [ ]  자동차 이름 입력

   ```java
   경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
   ```

- [ ]  시도할 횟수

   ```java
   시도할 횟수는 몇 회인가요?
   ```


**출력**

- [ ]  실행 결과

   ```java
   실행 결과
   pobi : -
   woni :
   jun : -
   
   pobi : --
   woni : -
   jun : --
   
   ```

- [ ]  우승자 출력

   ```java
   최종 우승자 : pobi, jun
   ```


**기능**

- [ ]  자동차 이름 파싱
    - [ ]  쉼표(,)를 기준으로 구분
    - [ ]  이름은 5자 이하

- [ ]  한 라운드 게임 진행
    - [ ]  자동차별 0~9 무작위 값을 구함
        - 0~3 : 멈춤
        - 4~9 : 전진

- [ ]  우승자 계산
    - [ ]  각 자동차가 몇 칸을 이동했는지 비교
    - [ ]  가장 많은 칸을 이동한 자동차가 우승

**예외 처리**

- [ ]  사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 을 발생시킨 후 애플리케이션은 종료되어야 한다.
